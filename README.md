# ScholarFlow

ScholarFlow 是一个面向硕博研究人员的个人科研操作系统。

它帮助研究者管理从研究想法产生，到实验实施、数据分析、论文 Figure 构建以及最终成果沉淀的完整科研流程。

不同于传统任务管理工具，ScholarFlow 关注科研过程的可追溯性：

项目在哪里推进？
实验如何完成？
数据如何产生？
Figure 如何构建？
论文结论依据是什么？

所有科研资产在一个系统中形成闭环。
